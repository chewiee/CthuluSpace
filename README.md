# CthuluSpace 🐙

A cosmic horror arcade game where you play as Cthulhu, devouring planets to grow stronger.

## How to Play

1. **Aim:** Move your mouse to aim Cthulhu.
2. **Launch:** Click and hold to charge/aim, then release to launch yourself towards a planet.
3. **Feast:** Collide with planets to eat them.
4. **Grow:** The more you eat, the bigger and faster you become.
5. **Survive:** Don't drift into the abyss!

## Controls

- **Mouse:** Aim and Launch

## Development

- Built with vanilla JavaScript and HTML5 Canvas.
- No dependencies required to run locally (just open `index.html`).
